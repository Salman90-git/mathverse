About MathVerse

A modern, responsive, client-side interactive mathematics learning platform crafted for students, educators, and curious minds.

🎯 Project Purpose & Overview

MathVerse was engineered as an advanced frontend capstone for the Web Engineering curriculum. The objective is to demonstrate that state-of-the-art, dynamic, and educational web applications can be constructed using pure modern web standards—without bulky runtime frameworks or heavy backend infrastructures.

From plotting multivariate mathematical curves and calculating matrix transformations step-by-step, to simulating probabilistic laws of large numbers and synthesizing chaotic fractals, MathVerse puts powerful visual computing directly in the browser.

⚙️ Technology Stack

Engineered completely client-side with zero build pipelines.

🌐

HTML5 & Semantic DOM

Strict accessibility compliance with ARIA landmarks, keyboard navigable tabs, and optimized canvas contexts.

🎨

Tailwind CSS (CDN)

Utility-first styling coupled with custom CSS properties for dark/light themes and sleek glassmorphism.

⚡

Vanilla JavaScript (ESM)

Modular architecture with strict JSDoc typing, shared local storage persistence, and zero npm runtime dependencies.

📐

KaTeX Math Typesetting

Ultra-fast LaTeX formula rendering for equations, theorem breakdowns, and interactive catalog filters.

📊

Chart.js 4.x

Hardware-accelerated statistical charts demonstrating the Law of Large Numbers, Collatz sequences, and user scores.

🧮

math.js 12.x

Safe mathematical expression parsing and continuous curve evaluation in the Graph Plotter engine.

⏱️ Development Phases

Phase A: Architecture & Design System

Established theme tokens, global layout injector, resilient localStorage wrapper, and responsive navigation.

Phase B: Visual Math Engines

Built multi-curve Canvas graph plotter with pan/zoom, step-by-step matrix decompositions, and quadratic solver.

Phase C: Numerical Labs & Formula Catalog

Created animated Sieve of Eratosthenes, probability simulation engines, unit converters, and searchable KaTeX formulas.

Phase D: Gamification & Progress Analytics

Integrated timed Quiz Arena with topic filtering, answer breakdowns, daily streak persistence, and trend charts.

Phase E: Chaos Theory & Validation

Implemented Mandelbrot Set (smooth coloring & zoom), Sierpiński triangle, and accessible contact validation.
